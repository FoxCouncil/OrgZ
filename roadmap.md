# OrgZ Roadmap

Quality, beauty, and simplicity - in that order when they conflict.
Tests reflect the finished product: nothing ships behind a capability flag without the
conformance suite proving it.

Status 0.10.10: suite 1963 (1955 pass, 8 skipped for missing oracles/wrong OS), zero build
warnings, gated per commit.

## Notes

Encoder builds, per platform. Kept because the quirks will bite again.

- win-x64: ffmpeg, flac (+ libFLAC, libFLAC++), lame.
- linux-x64: ffmpeg from BtbN's LGPL build via WSL2 (Windows' bsdtar can't read the
  `.tar.xz`). flac and lame built from source and statically linked by
  `scripts/build-encoders-linux.sh`. An AppImage has no dependency mechanism, so static
  matters.
- osx-arm64: ffmpeg 7.1 (LGPL-clean, AudioToolbox alac/aac) plus flac and lame, built on
  build-mac. macOS can't statically link libSystem, so only our own libs are static; verified
  with `otool -L`. Both scripts pin `MACOSX_DEPLOYMENT_TARGET=11.0` and assert the resulting
  minos - without it clang stamps the build machine's OS and the binary won't launch on
  anything older.
- Comparing a rip round-trip: compare decoded PCM, not files. ffmpeg writes a `LIST` chunk
  into WAV that flac drops, so `cmp` reports a 34-byte difference that isn't data loss.

Auto-update takes one UAC prompt per update: Program Files isn't user-writable, so
`Update.exe` re-launches elevated. That's the trade for silent disc and iPod access.

Two Avalonia DataGrid bugs the shared grid works around, both measured in
`MediaGridColumnRebuildTests` / `MediaGridGroupCollapseTests`:

- `Columns.Clear()` under grouping throws. `ClearItems()` empties `ItemsInternal` but leaves
  `RowGroupSpacerColumn.IsRepresented` set, so the next `InsertItem()` offsets by one into an
  empty list. Remove columns one at a time instead.
- `CollapseRowGroup` no-ops until the grid has built its row-group info. A synchronous
  `UpdateLayout()` builds it so the collapse lands in the same dispatcher turn.
